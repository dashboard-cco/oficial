## Estrutura para subir no GitHub

Envie todos os arquivos na raiz do repositório:

```
index.html
styles.css
config.js
supabase.js
data.js
app.js
schema_supabase_sugestao.sql
README.md
```

Depois atualize o navegador com Cmd + Shift + R.
